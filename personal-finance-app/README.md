# Personal Finance Manager

Desktop-приложение для удобного учета доходов и расходов.

## Функциональность
- Запись доходов и расходов по имеющимся категориям
- Расчет и подсвечивание текущего баланса
- Окно аналитики с суммарными итогами по каждой категории
- Автоматическое сохранение всех данных в файл `transactions.csv`

## Запуск
1. Установите Python 3.7+
2. Запустите основной интерфейс: `python finance_gui.py`
3. Вносите данные через верхнюю форму и отслеживайте статистику
